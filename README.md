# Client สุริยันต์ดับดารา (Windows)

โปรแกรมห่อเว็บ https://play.edensoft.net/ ให้เป็นแอปบนเดสก์ท็อป ใช้เหมือนเบราว์เซอร์ ไม่แตะไฟล์เกมใดๆ

## ฟีเจอร์
- เกมทำงานเต็มสปีดแม้หน้าต่างถูกบังหรืออยู่พื้นหลัง (ปิดการหน่วงของแท็บ)
- โหมด PiP: หน้าต่างเล็กลอยบนสุด ย่อได้ถึง 64×48 พิกเซล และย่อหน้าเกมให้พอดีหน้าต่าง
- ซ่อนเกมลงถาดระบบพร้อมปิดเสียง (F8) และเรียกกลับจากโปรแกรมอื่นได้ (Ctrl+Shift+H)
- แถบควบคุมธีมน้ำเงิน–ทอง
- ตัวติดตั้งเลือกโฟลเดอร์ได้ และสร้าง Shortcut บนเดสก์ท็อป
- Login ค้างอยู่ตามปกติ (เก็บ cookie/localStorage ในโฟลเดอร์ข้อมูลของแอป)

## คีย์ลัด
| คีย์ | ทำอะไร |
|---|---|
| Ctrl+Shift+P | สลับ PiP / จอปกติ |
| F11 หรือ Alt+Enter | สลับเต็มหน้าจอ |
| Esc | ออกจากเต็มหน้าจอ / กลับจาก PiP |
| F1 | แสดงวิธีใช้ |
| F5 | โหลดหน้าเกมใหม่ |
| F8 | ซ่อนเกมและปิดเสียง |
| Ctrl+Shift+H | ซ่อน/เรียกกลับ (ใช้ได้จากโปรแกรมอื่น) |

## วิธีรัน / สร้างตัวติดตั้ง
แบบง่าย (ไม่ต้องพิมพ์คำสั่ง): ติดตั้ง Node.js แล้วดับเบิลคลิก `1-เปิดเกม.bat` เพื่อเล่น หรือ `2-สร้างไฟล์ติดตั้ง.bat` เพื่อสร้างไฟล์ติดตั้ง .exe

แบบพิมพ์คำสั่งเอง:
1. ติดตั้ง Node.js (เวอร์ชัน LTS) จาก https://nodejs.org
2. เปิด Terminal ในโฟลเดอร์นี้ แล้วรัน `npm install`
3. ทดลองรัน: `npm start`
4. สร้างไฟล์ติดตั้ง: `npm run dist` ได้ไฟล์ `dist/Surisan Client Setup 1.0.0.exe`

## ปรับแต่ง
ค่าต่างๆ อยู่ด้านบนของ `main.js` เช่น `GAME_URL`, ขนาดหน้าต่าง PiP (`PIP_SIZE`), ขนาดอ้างอิงที่เกมถูกย่อตอน PiP (`BASE_W/BASE_H`), คีย์ลัดซ่อน (`HIDE_KEY`) สีของแถบแก้ใน `bar.html` ไอคอนแทนที่ `icon.png` ด้วยไฟล์ 256×256 ขึ้นไป

## เมนูโดเนท
กดปุ่ม "โดเนท" บนแถบ (ถัดจาก PiP) จะมีหน้าต่างแสดงรูป ให้แทนที่ไฟล์ `donate.png` ในโฟลเดอร์นี้ด้วยรูปของคุณ (ใช้ชื่อเดิม) แล้วรัน `1-เปิดเกม.bat` หรือสร้างไฟล์ติดตั้งใหม่

## หมายเหตุ
- ถ้าลากหน้าต่างด้วยแถบไม่ได้ในเวอร์ชัน Electron ที่ใช้ ให้แจ้งมา จะเปลี่ยนวิธีทำแถบ
- ถ้าจะแจกให้คนอื่น ควรขออนุญาตเจ้าของเว็บเกมก่อน
